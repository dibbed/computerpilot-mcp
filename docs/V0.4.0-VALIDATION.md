# ComputerPilot MCP v0.4.0 Release Validation

Date: 2026-09-30

## Scope

v0.4.0 is the cross-platform operations, observability, performance, and runtime-hardening release following v0.3.0.

The release includes the expanded local Control Panel, runtime/tool activity snapshots, Secure Tunnel transport diagnostics and poll-stall recovery, Recent Jobs/Recent Operations inspection, durable job/workflow/process hardening, state-retention safety, and runtime maintenance/performance improvements.

## Compatibility invariants

- Public project/package identity remains ComputerPilot MCP / `computerpilot-mcp`.
- The protocol-level MCP server identifier remains `ali_windows_agent_mcp`.
- Windows retains native desktop/UI Automation and Job Object ownership.
- Linux/macOS retain the portable core and POSIX process-group ownership.
- Release packages do not vendor upstream tunnel-client/Cloudflared executables.
- Linux arm64 and macOS amd64 remain deterministic package/updater targets without a dedicated native hosted-runner claim.

## Required local release checks

The final release-preparation SHA must pass:

- full pytest;
- Ruff;
- mypy;
- Python compile/startup validation;
- full startup Doctor;
- deterministic packaging for all five supported targets;
- checksum verification;
- release manifest/version inspection;
- Git diff/working-tree cleanliness checks.

The exact results are recorded in the final preparation commit after the checks complete.

## GitHub cross-platform gates

Publication is guarded by the repository workflows:

- CI on Windows, Linux, and macOS with Python 3.10 and 3.12;
- Platform Release Validation on Windows, Linux, and macOS with Python 3.12;
- Release Packaging Smoke for all five target archives;
- exact-SHA publication checks before creating the tag/release.

The release workflow only publishes from a `main` commit whose subject is exactly `release: v0.4.0`, and it verifies the same SHA has successful CI and packaging gates before creating the GitHub release.

## Artifact contract

Expected archives:

- `computerpilot-mcp-v0.4.0-windows-amd64.zip`
- `computerpilot-mcp-v0.4.0-linux-amd64.tar.gz`
- `computerpilot-mcp-v0.4.0-linux-arm64.tar.gz`
- `computerpilot-mcp-v0.4.0-macos-amd64.tar.gz`
- `computerpilot-mcp-v0.4.0-macos-arm64.tar.gz`
- `SHA256SUMS.txt`

Every archive must contain `RELEASE-MANIFEST.json` with project `computerpilot-mcp`, version `0.4.0`, the source commit, target, and managed-runtime policy.
