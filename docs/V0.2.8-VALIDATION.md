Date: 2026-09-24

v0.2.8 is a patch release for control-plane API-key loading resilience. Publication remains fail-closed: the exact release commit on `main` must have successful CI, Platform Release Validation, and Release Packaging Smoke runs.

## Patch scope

The release contains the post-v0.2.7 fixes merged through PR #22 and PR #23:

- UTF-8 BOM stripping for control-plane API keys;
- UTF-16 LE/BE secret-file decoding;
- surrounding quote and whitespace normalization;
- controlled handling of decode failures;
- shared key-normalization behavior across bootstrap, Doctor, Supervisor, and managed tunnel runtime code.
