## Runtime preservation

Local `.agent_state`, `.secrets`, `.venv`, durable jobs/workflows, and managed tunnel cache remain local machine state and are never packaged.

A machine upgrading from an older managed full-client cache will migrate to the `tunnel-client-runtime-cloudflared` flavor on the next cold tunnel startup because legacy metadata without the new runtime flavor is not accepted as the selected managed runtime.
