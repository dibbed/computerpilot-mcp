# v0.2.7 - Cross-Platform Preview

v0.2.7 moves the project from a Windows-only runtime architecture to a capability-aware cross-platform core while preserving the established Windows feature surface and compatibility identifiers.

## Highlights

- Windows, Linux, and macOS startup/health/full-test CI.
- Portable Python bootstrap and executable `start_mcp.sh`.
- Windows Job Objects plus POSIX process-group ownership.
- Windows CMD, optional PowerShell, and POSIX `sh` terminal backends.
- Portable system diagnostics with Windows/Linux/macOS service and installed-software adapters.
- Cross-platform audit/memory/recovery/tunnel inter-process locking.
- Verified managed OpenAI Secure Tunnel updates for Windows/Linux/macOS amd64/arm64.
- Cross-platform Doctor, benchmark, durable-job and workflow soak release gate.
- Deterministic multi-platform release artifacts with SHA-256 manifest.
- Windows desktop screenshots/input and semantic UI Automation remain Windows-only and capability-gated.

## Native validation coverage

| Host | Python | Validation |
| --- | --- | --- |
| Windows amd64 | 3.10, 3.12 | Full CI |
| Linux amd64 | 3.10, 3.12 | Full CI |
| macOS arm64 | 3.10, 3.12 | Full CI |
| Windows/Linux/macOS | 3.12 | Real launcher + Doctor + benchmark + workflow soak |

Linux arm64 and macOS amd64 packages are produced from the same architecture-neutral Python source and have managed tunnel-client asset mappings, but this release does not claim dedicated native hosted-runner execution for those two combinations.

- `windows-agent-mcp-v0.2.7-linux-amd64.tar.gz`

- `SHA256SUMS.txt`

The Windows artifact contains the tracked Windows amd64 tunnel/Cloudflared offline fallback. Linux/macOS artifacts omit those Windows binaries and acquire a verified official managed tunnel runtime on demand.

## Compatibility

The repository name `windows-agent-mcp` and MCP server identifier `ali_windows_agent_mcp` remain unchanged to avoid breaking existing integrations. User-facing documentation and CLI descriptions now reflect the cross-platform runtime.

## Security

Release archives are generated from exact tracked Git blobs plus a generated release manifest. Packaging fails closed if runtime/secrets/build-state paths are tracked. Managed tunnel downloads require official HTTPS assets, matching SHA-256 evidence and binary-version validation before immutable publication.
