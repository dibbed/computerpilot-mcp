# ComputerPilot MCP v0.6.0 - Native Document Intelligence

ComputerPilot MCP v0.6.0 adds first-class native document adapters for Excel, DOCX, and PDF so common document work can be performed through structured MCP tools without launching desktop applications.

## Highlights

### Excel

- Add structured workbook inspection and sheet listing for `.xlsx` and safely supported `.xlsm` files.
- Add bounded range reads, value/formula search, formula inspection, and table metadata.
- Add guarded range writes/clears, sheet add/rename/delete, formula assignment, and table creation.
- Serialize same-file mutations while allowing independent workbooks to proceed concurrently.
- Support optional SHA-256 preconditions so stale external edits are rejected before mutation.
- Preserve XLSM VBA project bytes only when staged serialization verifies they remain byte-identical.
- Reject macro-bearing XLSX files and unsupported macro-loss scenarios instead of silently stripping content.
- Validate OOXML archive paths, duplicate members, encryption flags, CRC integrity, entry limits, expanded-size budgets, and excessive compression before OpenPyXL parsing.

### DOCX

- Add structure and core-metadata inspection.
- Add bounded paragraph and table-cell reads plus bounded text search.
- Add conservative text replacement, paragraph insertion, simple table-cell replacement, and simple DOCX creation.
- Preserve supported run formatting and fail closed when a replacement crosses differently formatted runs.
- Validate DOCX ZIP structure, required members, traversal attempts, duplicate members, encryption, CRC failures, and decompression limits.
- Keep `.docm`, tracked changes, comments, headers/footers, and arbitrary WordprocessingML mutation explicitly unsupported.

### PDF

- Add PDF page-count, encryption-state, and metadata inspection.
- Add bounded single-page and multi-page text extraction with explicit page/character limits and optional file-backed delivery.
- Add deterministic new-PDF creation from plain text and a documented Markdown subset.
- Reject encrypted PDF text extraction unless the caller provides a decrypted input.
- Keep arbitrary editing of existing PDFs outside the v0.6.0 contract.

### Recovery and artifacts

- Return document artifact descriptors containing path, SHA-256, byte size, and media type.
- Use same-directory staging, format-specific round-trip validation, backups, and atomic publication for mutations.
- Durably checkpoint the expected final file hash before atomic replacement so a crash after the side effect can be reconciled without blind replay.
- Add a dedicated `documents` tool profile while preserving the existing full profile and typed tool catalog.

## Dependencies

The native-document runtime uses mature format libraries recorded in the project runtime dependencies:

- OpenPyXL for Excel;
- python-docx for DOCX;
- pypdf for PDF inspection/extraction;
- ReportLab for deterministic PDF creation.

These dependencies are part of the normal portable runtime for v0.6.0.

## Compatibility

v0.6.0 includes all v0.5.0 Semantic Browser capabilities.

The protocol-level MCP server identifier remains:

`ali_windows_agent_mcp`

Existing client and Secure Tunnel configurations therefore do not require an identifier migration.

The document domain is portable across supported Windows, Linux, and macOS hosts. Windows-only UI Automation remains capability-gated and is not required for native document operations.

## Packaging contract

v0.6.0 continues deterministic packaging for:

- `computerpilot-mcp-v0.6.0-windows-amd64.zip`
- `computerpilot-mcp-v0.6.0-linux-amd64.tar.gz`
- `computerpilot-mcp-v0.6.0-linux-arm64.tar.gz`
- `computerpilot-mcp-v0.6.0-macos-amd64.tar.gz`
- `computerpilot-mcp-v0.6.0-macos-arm64.tar.gz`
- `SHA256SUMS.txt`

Linux arm64 and macOS amd64 remain deterministic package/updater targets without a dedicated native hosted-runner claim.
