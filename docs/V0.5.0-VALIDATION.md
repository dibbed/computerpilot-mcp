# ComputerPilot MCP v0.5.0 Release Validation

Date: 2026-10-01

## Scope

v0.5.0 is the Semantic Browser release following v0.4.0. It adds bounded semantic page snapshots and queries, generation-scoped node references, semantic click/fill/select operations, structured waits, explicit tab control, bounded page extraction, controlled upload/download handling, and browser semantic health metrics.

## Compatibility invariants

- Public project/package identity remains ComputerPilot MCP / `computerpilot-mcp`.
- The protocol-level MCP server identifier remains `ali_windows_agent_mcp`.
- Existing selector-based browser tools remain available.
- Semantic features reuse the existing Playwright session/context/process lifecycle instead of introducing a second browser runtime.
- Stale semantic references fail closed after navigation or semantic mutation.
- Release packages do not vendor upstream tunnel-client/Cloudflared executables.
- Linux arm64 and macOS amd64 remain deterministic package/updater targets without a dedicated native hosted-runner claim.
