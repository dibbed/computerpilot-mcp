# v0.2.8 - Connection Resilience Patch

v0.2.8 is a focused patch release on top of v0.2.7. It keeps the cross-platform architecture and release contract unchanged while hardening how the Windows runtime loads the Secure MCP Tunnel control-plane API key.

## Fixed

- Strip a UTF-8 BOM before validating `CONTROL_PLANE_API_KEY`.
- Decode UTF-16 LE/BE key files safely when Windows tooling saved the secret with UTF-16 encoding.
- Normalize surrounding quotes and incidental whitespace without exposing or logging the key.
- Handle invalid/undecodable secret text as a controlled startup/diagnostic failure instead of an unhandled Unicode decode exception.
- Use the same normalization path from bootstrap, Doctor, Supervisor, and managed tunnel runtime helpers.

These fixes address the class of failures where the tunnel process could fail with a malformed control-plane API key even though the stored key itself was valid.

## Compatibility

- No tool names or public MCP contracts are removed.
- The project remains capability-aware across Windows, Linux, and macOS.
- The repository name `windows-agent-mcp` and MCP server identifier `ali_windows_agent_mcp` remain unchanged.
- Existing `.agent_state`, `.secrets`, durable jobs, workflows, and managed tunnel state remain local runtime state and are not packaged into releases.
