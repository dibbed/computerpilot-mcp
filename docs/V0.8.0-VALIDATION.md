# ComputerPilot MCP v0.8.0 Release Validation

Validation date: 2026-10-13

## Scope

v0.8.0 introduces the Extensibility & Agent Foundation, adding bounded external MCP provider integration alongside the native runtime while preserving baseline native contracts and zero-extension operation.

Key validated capabilities:
- Bounded stdio transport with Windows Job Object and POSIX process group tree reaping.
- Offline non-network JSON Schema validation with monotonic catalog generations.
- Guarded execution with immutable admission leases and Core `ExtensionResult` envelopes.
- Two-stage mutation checkpointing (`prepared` -> `may_dispatch`) and uncertainty durability (no blind replay).
- Adaptive Execution Router integration with `external.mcp` candidate generation and native priority.
- Read-only health snapshots, loopback control panel views, and rolling telemetry.
- Offline atomic configuration publication with Compare-and-Swap (CAS) revision checks.
- Frozen resource limits and performance ceilings (Section 35 / M14).
