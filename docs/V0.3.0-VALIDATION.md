# ComputerPilot MCP v0.3.0 Release Validation

Date: 2026-09-25

## Scope

v0.3.0 is the ComputerPilot MCP rebrand release. It changes public naming, package/release metadata, artifact prefixes, discovery-oriented README content, and repository metadata while preserving the protocol-level MCP server identifier for compatibility.

## Compatibility invariant

`core/config.py` must continue to expose:

`server_name = "ali_windows_agent_mcp"`

The public MCP display title may change to ComputerPilot MCP, but existing client/tunnel configuration must not require an identifier migration.
