# ComputerPilot MCP v0.3.0 Release Validation

Date: 2026-09-25

## Scope

v0.3.0 is the ComputerPilot MCP rebrand release. It changes public naming, package/release metadata, artifact prefixes, discovery-oriented README content, and repository metadata while preserving the protocol-level MCP server identifier for compatibility.

## Compatibility invariant

`core/config.py` must continue to expose:

`server_name = "ali_windows_agent_mcp"`

The public MCP display title may change to ComputerPilot MCP, but existing client/tunnel configuration must not require an identifier migration.

## Required validation

Before publication:

- startup check reports v0.3.0 with a unique tool catalog;
- full pytest passes;
- Ruff passes;
- mypy passes;
- compileall passes;
- MCP health passes;
- Windows platform validation passes;
- all five deterministic packages build with the `computerpilot-mcp-v0.3.0` prefix;
- release manifests report `project = "computerpilot-mcp"`;
- the Windows package contains no vendored tunnel-client or Cloudflared runtime files;
- exact-head GitHub CI, Platform Release Validation, and Release Packaging Smoke pass on release-preparation and final release-trigger commits;
- the published GitHub release targets the final release SHA;
- the published Windows artifact is inspected again after publication.

## Repository migration

After the code/release preparation is merged, the GitHub repository is renamed from `dibbed/windows-agent-mcp` to `dibbed/computerpilot-mcp`. The local `origin` remote is then updated to the canonical new URL and verified against `main`.
