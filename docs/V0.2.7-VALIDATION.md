## Architecture coverage

Artifacts target Windows amd64, Linux amd64/arm64 and macOS amd64/arm64. Hosted native CI exercises Windows amd64, Linux amd64 and macOS arm64. Linux arm64 and macOS amd64 use the same Python source and verified upstream tunnel asset mapping but are not represented as dedicated native hosted runners in this release.

## Release integrity

`scripts.package_release` reads exact Git blobs, rejects tracked runtime/secrets/build state, verifies the requested version against `core/config.py` and `pyproject.toml`, uses deterministic ZIP/TAR metadata, preserves POSIX executable modes, omits Windows fallback executables from POSIX archives, embeds `RELEASE-MANIFEST.json`, and emits `SHA256SUMS.txt`.

The publication workflow waits for normal CI and packaging smoke after Platform Release Validation succeeds, then creates the GitHub tag/release against the exact validated main SHA. Existing release tags are left unchanged.
