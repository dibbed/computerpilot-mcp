# ComputerPilot MCP v0.4.0 - Operations, Observability & Reliability

ComputerPilot MCP v0.4.0 is a cross-platform operations and runtime-hardening release.

It expands the local Control Panel into an observability and diagnostics surface, strengthens Secure Tunnel health/recovery behavior, improves durable job/workflow/process lifecycle correctness, and reduces unnecessary synchronous/runtime maintenance work.

## Highlights

- Rebuilt local Control Panel with incident-first health, sticky navigation, runtime/build identity, resource budgets, storage/performance summaries, transport diagnosis, workflow/recovery visibility, Doctor output, audit history, memory metadata, and redacted diagnostics export.
- Added detailed Recent Jobs views with bounded stdout/stderr, command/cwd/process metadata, cancellation controls, and keyboard-accessible modal interaction.
- Upgraded Recent Operations with search, outcome filters, paging, status chips, full-target inspection, and safe metadata details.
- Added generation-scoped runtime-health and tool-activity snapshots so the Supervisor can distinguish local MCP activity from upstream transport inactivity.
- Added detailed Secure Tunnel transport classifications, bounded transport history, and a conservative confirmed poll-stall watchdog.
- Hardened job/workflow/process recovery against stale PID metadata, process reuse, disappearing children, concurrent migrations, crash checkpoints, stale operation state, and interrupted cleanup.
- Reduced event-loop and maintenance overhead through offloaded health collection, fewer redundant filesystem/database reads, indexed queue access, batched timing writes, and bounded cleanup paths.
- Suppressed expected loopback client disconnect write failures, including Windows WinError 10053, without hiding unrelated server failures.

## Cross-platform contract

The portable ComputerPilot MCP core remains available across Windows, Linux, and macOS:

- filesystem/editing and project analysis;
- Git, testing, diagnostics, and code intelligence;
- terminal/process execution with platform-specific ownership;
- browser automation;
- durable jobs, recovery, workflows, and project memory;
- Secure Tunnel managed-runtime selection for supported OS/architecture mappings.

Windows additionally exposes native desktop screenshots/input, semantic UI Automation, Windows CMD, SCM/Registry-backed system inspection, and Job Object process ownership.

Linux and macOS remain preview for the portable core. Native Windows desktop/UI Automation is not emulated on POSIX hosts.

v0.4.0 publishes deterministic packages for five targets:

- `computerpilot-mcp-v0.4.0-windows-amd64.zip`
- `computerpilot-mcp-v0.4.0-linux-amd64.tar.gz`
- `computerpilot-mcp-v0.4.0-linux-arm64.tar.gz`
- `computerpilot-mcp-v0.4.0-macos-amd64.tar.gz`
- `computerpilot-mcp-v0.4.0-macos-arm64.tar.gz`
- `SHA256SUMS.txt`

Linux arm64 and macOS amd64 are package/updater targets. This release does not claim a dedicated native hosted-runner validation lane for those two architecture combinations.

## Compatibility

The protocol-level MCP server identifier remains:

`ali_windows_agent_mcp`

Existing client and Secure Tunnel configurations therefore do not require an identifier migration.

Project release archives continue to exclude upstream tunnel-client/Cloudflared binaries. Tunnel mode downloads and verifies the official managed runtime separately.
