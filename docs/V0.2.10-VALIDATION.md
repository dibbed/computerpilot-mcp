# v0.2.10 Release Validation

Date: 2026-09-25

v0.2.10 is a patch release for live managed-runtime migration on Windows.

## Reproduced issue

On a host upgraded from v0.2.8/v0.2.9-era state, the active tunnel process was:

`.agent_state/tunnel-runtime/v0.0.14/windows-amd64/tunnel-client.exe`

The new v0.2.9 managed updater selected the official `tunnel-client-runtime-cloudflared-v0.0.14-windows-amd64.zip`, but installation attempted to replace the existing `v0.0.14/windows-amd64` directory. Windows returned `WinError 5 / Access is denied` because the legacy executable in that directory was still running.

## Fix

The managed runtime flavor now installs under:

`.agent_state/tunnel-runtime/<version>/<platform>/tunnel-client-runtime-cloudflared/`

This makes same-version flavor migration additive instead of destructive.

## Local validation

The fix passed:

- 63 focused tunnel runtime / Doctor / packaging tests;
- full pytest;
- Ruff with zero violations;
- mypy with zero issues across 193 source files.

A real live migration on Windows amd64 was then executed with the legacy `tunnel-client.exe` still running. It succeeded and produced:

- managed upstream version: `v0.0.14`;
- managed flavor: `tunnel-client-runtime-cloudflared`;
- selected binary: `tunnel-client-runtime-cloudflared.exe`;
- verified archive: `tunnel-client-runtime-cloudflared-v0.0.14-windows-amd64.zip`;
- updated `current.json` pointing to the flavor-specific runtime;
- legacy `tunnel-client.exe` process still alive after migration.
