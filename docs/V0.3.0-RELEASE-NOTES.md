# ComputerPilot MCP v0.3.0 - Rebrand Release

ComputerPilot MCP is the new public identity of the project previously published as `windows-agent-mcp` / Local Developer Agent MCP.

The rebrand reflects the actual scope of the runtime: cross-platform computer use and developer automation over MCP, with native Windows desktop capabilities plus portable filesystem, terminal, browser, Git, testing, durable jobs, recovery, and workflow tooling.

## What changes

- GitHub repository name: `computerpilot-mcp`
- Public project title: **ComputerPilot MCP**
- Python project metadata name: `computerpilot-mcp`
- Release artifact prefix: `computerpilot-mcp-v<version>`
- MCP display title and description: ComputerPilot MCP / cross-platform computer-use and developer automation
- Tunnel updater user agent: `computerpilot-mcp-tunnel-updater`
- Release manifest project field: `computerpilot-mcp`
- README, badges, search terminology, package metadata, and GitHub repository metadata are aligned to the new identity.

## Compatibility

The protocol-level MCP server identifier remains:

`ali_windows_agent_mcp`

That identifier is intentionally retained so existing MCP client configurations and Secure Tunnel profiles do not need to be rewritten for the branding change.

Historical v0.2.x releases and documentation retain their original artifact/repository naming where they describe the historical release.

## Distribution

v0.3.0 publishes:

- `computerpilot-mcp-v0.3.0-windows-amd64.zip`
- `computerpilot-mcp-v0.3.0-linux-amd64.tar.gz`
- `computerpilot-mcp-v0.3.0-linux-arm64.tar.gz`
- `computerpilot-mcp-v0.3.0-macos-amd64.tar.gz`
- `computerpilot-mcp-v0.3.0-macos-arm64.tar.gz`
- `SHA256SUMS.txt`

As in v0.2.9+, these project packages do not vendor upstream tunnel-client/Cloudflared binaries. Tunnel mode downloads and verifies the official managed runtime separately.
