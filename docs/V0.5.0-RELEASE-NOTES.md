# ComputerPilot MCP v0.5.0 - Semantic Browser

ComputerPilot MCP v0.5.0 upgrades browser automation from selector-first actions into a bounded, structure-first semantic browser subsystem while preserving the existing Playwright process/session lifecycle.

## Highlights

- Add bounded semantic page snapshots with accessible roles, names, state, explicit truncation metadata, and generation-scoped node references.
- Add targeted semantic queries so agents can find page elements without serializing the full page tree.
- Add semantic click and fill operations using node refs, roles, accessible names, labels, text, and test IDs instead of screenshot coordinates.
- Reject stale semantic references after navigation or mutation instead of silently acting on changed page state.
- Fail closed on ambiguous semantic mutation targets unless the caller explicitly selects a deterministic match.
- Add structured browser waits instead of relying on arbitrary fixed sleeps.
- Add semantic selection and explicit tab listing, activation, and close operations.
- Add bounded page extraction for text, links, tables, form fields, and selected subtrees.
- Add controlled upload and download handling with explicit local upload paths, sanitized download names, controlled runtime storage, and configured byte limits.
- Add semantic browser health counters for snapshots, latency accumulation, nodes, truncation, action success/failure, stale refs, and downloaded bytes.

## Compatibility

Existing selector-based browser tools remain available. Semantic browser tools extend the current Playwright manager rather than replacing it.

Browser sessions continue to use isolated contexts and compatible shared browser-process pooling. Existing idle reclamation and lifecycle behavior remain in place.

The protocol-level MCP server identifier remains:

`ali_windows_agent_mcp`

Existing client and Secure Tunnel configurations therefore do not require an identifier migration.

## Platform and packaging contract

The semantic browser surface is part of the portable browser domain. Browser execution still requires Playwright and an installed compatible browser runtime.

v0.5.0 continues the deterministic five-target packaging contract:

- `computerpilot-mcp-v0.5.0-windows-amd64.zip`
- `computerpilot-mcp-v0.5.0-linux-amd64.tar.gz`
- `computerpilot-mcp-v0.5.0-linux-arm64.tar.gz`
- `computerpilot-mcp-v0.5.0-macos-amd64.tar.gz`
- `computerpilot-mcp-v0.5.0-macos-arm64.tar.gz`
- `SHA256SUMS.txt`

Linux arm64 and macOS amd64 remain deterministic package/updater targets without a dedicated native hosted-runner claim.
