# ComputerPilot MCP v0.6.0 Release Validation

Date: 2026-10-01

## Scope

v0.6.0 is the Native Document Intelligence release following v0.5.0 Semantic Browser. It adds portable, typed XLSX/XLSM, DOCX, and PDF adapters with bounded reads, conservative mutations, deterministic document creation, artifact descriptors, archive hardening, file-level concurrency controls, and durable recovery postconditions.

## Release lineage

- v0.5.0 was published from exact main/tag SHA `791748bf43a9cb109afea19bb7f7a945598223ab`.
- The v0.6.0 release-preparation branch was created from that published v0.5.0 main state.
- The G2 document commits were applied in their original logical order on top of v0.5.0, preserving release history and keeping v0.5.0 changelog/release records intact.

## Compatibility invariants

- Public project/package identity remains ComputerPilot MCP / `computerpilot-mcp`.
- The protocol-level MCP server identifier remains `ali_windows_agent_mcp`.
- v0.6.0 contains the complete v0.5.0 Semantic Browser surface.
- The document domain works directly on files and does not require Microsoft Office GUI automation.
- Windows-only UI Automation remains capability-gated; native document adapters are portable.
- Existing typed filesystem/browser/system/developer tools remain available.
- Release packages do not vendor upstream tunnel-client/Cloudflared executables.
- Linux arm64 and macOS amd64 remain deterministic package/updater targets without a dedicated native hosted-runner claim.

## Document safety evidence

The implemented contract includes:

- same-file document mutation serialization and independent-target concurrency;
- optional SHA-256 stale-write preconditions;
- same-directory staging plus format-specific validation before atomic publication;
- recoverable backups;
- durable final-file hash checkpointing before replacement for crash reconciliation;
- bounded Excel/DOCX OOXML archive structure and expansion validation;
- fail-closed XLSM macro preservation checks;
- fail-closed DOCX mixed-format text replacement;
- bounded PDF text extraction and explicit encrypted-input handling.
