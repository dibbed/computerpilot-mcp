# ComputerPilot MCP v0.7.1 Release Validation

Validation date: 2026-10-11

## Scope

v0.7.1 is a focused Windows console-shutdown reliability patch on top of v0.7.0 Adaptive Execution Router.

The release changes the Windows launcher/bootstrap/Supervisor interrupt path so:

- the first Ctrl+C requests a graceful Supervisor shutdown and bounded runtime drain;
- a second Ctrl+C requests prompt forced cleanup;
- intentional console shutdown does not re-enter the launcher crash-restart loop;
- the SIGINT path is safe if it interrupts lock-protected Supervisor lifecycle code;
- the live Windows start path no longer keeps an intermediate PowerShell process between the console and ComputerPilot after virtual-environment setup.

The patch does not add/remove MCP tools, change workflow schema v6, change `deterministic-v1` routing behavior, or alter the cross-platform capability contract.

## Exact-SHA publication rule

After release preparation is merged, a final PR must produce a `main` commit whose subject is exactly:

```text
release: v0.7.1
```

The `Publish Release` workflow will publish only after Platform Release Validation succeeds for that exact `main` SHA and confirms successful same-SHA CI and Release Packaging Smoke runs. Publication rebuilds all five artifacts from the exact release SHA, re-verifies `SHA256SUMS.txt`, requires `docs/V0.7.1-RELEASE-NOTES.md`, and creates tag/release `v0.7.1` only if it does not already exist.

Existing published tags/releases, including v0.7.0, remain immutable.
